How it works

Simple inputs, exact matrix lookup

This version deliberately keeps the decision logic transparent and faithful to the supplied spreadsheet.

1

Enter the student profile

Choose Year 7–12, expected length of stay, literacy level and numeracy level.

2

Match the source matrix

The app constructs an exact key from those four variables and retrieves the curriculum options entered against that exact combination.

3

Review the options

Each result is displayed as a curriculum card. Where the spreadsheet contains a process link, an external-link button is shown.

4

Print or copy a summary

The result can be printed, saved to PDF using the browser print dialog, or copied as plain text for use in another document.

Privacy by design

This static prototype does not transmit form data to a server. Avoid entering student names, diagnoses or other identifying health information.
